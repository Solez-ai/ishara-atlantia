ISHARA
On-Device Sign Language Recognition for Everyone
Artificial Intelligence | Machine Learning | Computer Vision
Problem Statement

72 million Deaf and hard-of-hearing people worldwide lack accessible digital sign language tools.

Current solutions require expensive GPUs and cloud infrastructure, excluding developing nations.

Bangladesh: 500,000+ Deaf individuals need accessible technology.

Proposed Solution
  • Lightweight models: 150 KB
  • On-device inference: CPU-only
  • Real-time: 20-30 FPS
  • Multilingual: BdSL, ASL tested
  • Privacy-first: No cloud required
How It Works

4-Step Pipeline:

  1. Capture video frames at 30 FPS
  2. MediaPipe hand/pose detection
  3. Extract 144D feature vectors
  4. Lightweight ML classification
Technology Stack
  • MediaPipe: Hand detection
  • scikit-learn: Classification
  • Python 3.10+
  • OpenCV, NumPy
  • Session-held-out validation
Expected Impact
  • Accessibility for 72M Deaf people
  • Works offline globally
  • Deployable on Raspberry Pi
  • Privacy-respecting on-device
  • Extensible to 300+ languages
Future Development
  • Expand to 500+ signs
  • Real-world signer data
  • Mobile app deployment
  • Platform integration
  • Regional dialect support
